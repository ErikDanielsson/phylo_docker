# phylo_docker (frozen fork)
This branch contains build recipes for RevBayes docker images based on build recipes in [sswinston/phylo_docker](https://github.com/sswiston/phylo_docker/).
This fork was created to freeze the RevBayes docker image at the `d86165c` revision to allow for reproducible analyses in the [`nf-host-rep`](https://github.com/ErikDanielsson/nf-host-rep) pipeline.
